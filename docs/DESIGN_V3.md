# OWL COMPILE UI 리디자인 v3 — 디자인 브리프 (UI만)

사용자 요청 흐름: ① "코딩게임 화면처럼 깔끔하게, 파란색·보라색으로"(구조 레퍼런스) → ② 새 이미지와 함께 "이런 디자인 느낌으로 해줘"(분위기 레퍼런스).
따라서 **구조는 v2(`docs/DESIGN_V2.md` §3~§4의 콘솔 레이아웃)를 유지하고, 색·질감·타이포·카드 처리는 이 문서로 바꾼다.** v2와 충돌하면 이 문서가 이긴다.
기능·규칙·API·서버·엔진·편집기 동작은 바꾸지 않는다(v2 §6과 같음).

## 1. 분위기 레퍼런스 (사용자가 보낸 "Fintech." 랜딩 페이지를 글로 옮김)

- **바탕**: 거의 순수한 검정. 가장자리 일부에 보라색 빛이 아주 옅게 번진다(오른쪽 아래 등).
- **내비게이션**: 왼쪽 로고 "Fintech."에서 앞 글자 "Fin"만 보라색. 가운데 작은 흰 링크들. 오른쪽에 **외곽선 버튼**(흰 1px 테두리, 투명 배경, 모서리 약 6px)과 **보라로 채운 버튼**(전기 보라 #4F1DFF 전후, 흰 글자).
- **히어로**: 화면 위쪽을 덮는 거대한 **빛나는 반원 아치**. 가장 안쪽은 거의 흰 라벤더, 바깥으로 전기 보라, 다시 검정으로 사라지는 링 모양 글로우. 그 위에 흰색 굵은 헤드라인 두 줄(기하학적 산세리프, 좁은 행간), 회백색 작은 부제, 버튼 두 개(보라 채움 + 외곽선).
- **로고 띠**: 얇은 흰 테두리(투명도 약 25%)의 둥근 사각 박스 안에 통계 "1,200+"와 파트너 로고들, 사이에 세로 구분선.
- **섹션 제목**: 흰 굵은 글씨 + 뒷부분만 보라("Innovating Tomorrow. **Building Today.**"에서 뒤 문장이 보라).
- **서비스 카드 3×2**: 검정에 가까운 카드, 얇은 회색 테두리, 모서리 약 10px. 왼쪽 위 보라 선 아이콘, 오른쪽 위 원 안의 화살표 아이콘, 흰 굵은 작은 제목, 회색 설명. **가운데 위 카드 하나만 보라 그라데이션으로 가득 채움**(밝은 전기 보라 → 짙은 남보라), 글자는 흰색.
- **보라 띠 섹션**: 화면 폭 전체의 짙은 보라 면. 가운데 흰 제목·부제, 아래 카드 4장은 투명 배경 + 반투명 흰 테두리, 큰 흰 숫자 "01"~"04", 오른쪽 위 화살표 아이콘, 흰 제목.
- **프로젝트 카드**: 검정 카드 + 얇은 테두리, 맨 위에 작은 보라 분류 라벨, 흰 제목, 회색 설명. 아래 보라 채움 버튼 "View All Projects".
- **후기**: 보라 카드들 위로 둥근 아바타가 반쯤 걸쳐 있다.
- **정리**: 검정 + 전기 보라 + 흰 글자, 얇은 밝은 테두리, 모서리 8~12px, 빛(글로우)은 히어로·강조 카드·버튼에만. 굵고 현대적인 산세리프. 파스텔·이모지·귀여운 요소 없음.

## 2. 우리 버전: "검은 관제실 + 전기 보라"

- v2의 남색 톤을 **검정 톤**으로, 주 강조색을 **전기 보라**로 바꾼다. 파랑은 보조 강조(링크·정보·이동 카드)로 남긴다(사용자가 처음에 "파란색과 보라색" 요청).
- 빛(글로우)과 그라데이션은 **정해진 곳에만** 쓴다(§4). 그 외 면은 평평한 검정 카드 + 얇은 테두리.

### 색 토큰 (v2 토큰 이름을 최대한 유지하고 값만 바꾼다. 새 토큰은 추가)

| 토큰 | 값 | 용도 |
|---|---|---|
| bg | #06050A | 앱 바탕 (보라 기운이 아주 약간 도는 검정) |
| rail | #09080F | 왼쪽 레일·헤더 |
| panel | #0F0E17 | 카드·패널 |
| panel-2 | #16141F | 패널 머리, 올라온 면, 호버 |
| inset | #0A0910 | 에디터·맵 뷰포트 |
| line | rgba(255,255,255,.10) | 기본 얇은 테두리 |
| line-strong | rgba(255,255,255,.20) | 외곽선 버튼, 강조 테두리 (입력칸 테두리는 3:1 을 위해 white/35, 포커스 violet-ink) |
| line-on-violet | rgba(255,255,255,.45) | 보라 면 위의 카드 테두리 |
| text | #F5F3FB | 본문·제목 |
| text-dim | #B3AEC6 | 보조 |

| violet | #5B2BFF (hover #6E45FF, press #4A1FE0) | **주 동작 버튼**, 활성 상태, 진행 막대, 선택 |
| violet-ink | #9F85FF | 검정 위의 보라 글자(헤드라인 강조 구, 링크형 라벨) — 대비 확보용 밝은 보라 |

| blue | #3D7BFF (hover #5B90FF) | 보조 강조: 정보, 링크, 참가 주소 |
| cyan | #22C3E6 | 둥지·성공 강조 (드물게) |
| danger / warn / ok | #FF5C7A / #F2B84B / #36D3A6 | 상태 전용 |

그라데이션·글로우 토큰(유틸리티로 제공):
- `bg-highlight` (강조 카드): linear-gradient(145deg, #6B3DFF 0%, #4A1CE6 50%, #2E0CA8 100%), 글자 흰색.
- `bg-band` (보라 띠): linear-gradient(180deg, #24098A 0%, #3512BE 100%).
- `glow-arc` (아치 글로우): 요소 위쪽에 큰 반원 링. radial-gradient로 안쪽 #EDE6FF → #8C6BFF → #5B2BFF → transparent, blur 적용. 화면 폭보다 넓게, 검정으로 자연스럽게 사라지게.
- `glow-soft` (옅은 번짐): 모서리 한쪽에 rgba(91,43,255,.18) 원형 번짐.
- `shadow-glow` (버튼·강조 카드): 0 0 0 1px rgba(111,69,255,.5), 0 8px 32px rgba(91,43,255,.35).

| 분류 | 역할 | 값 | 글자 |

- 모양은 v2 그대로(홈·돌기 유지, 4px 모서리). 검정 바탕에서 카드 윗면 하이라이트는 rgba(255,255,255,.18) 1px.
- 드래그 중 카드: shadow-glow. 연결선: violet 2px + 끝점 원. 고스트: violet 점선 외곽선.

### 타이포

- 한글: Pretendard Variable 400/500/600/700. 제목은 700, 자간 -0.02em, 행간 1.2.
- 라틴 문자·큰 숫자(점수, 01~05, 게임 코드 제외): **Manrope** 600/700/800 (Google Fonts). `font-display` 유틸리티로 제공. 스택: Manrope, Pretendard Variable, system-ui.
- 코드·타이머·게임 코드·줄 번호: JetBrains Mono (v2 그대로).
- 제목의 강조 구는 violet-ink 색(예: "팀으로 조립하고, **부엉이를 둥지로.**").
- 크기: 본문 14px(폰 15px), 패널 제목 14px 600, 화면 제목 20~24px 700, 히어로 헤드라인(로그인·홈·보드 대기) 32~44px 700.

### 모양

- 모서리: 버튼·입력 8px, 카드·패널 12px, 시트·모달 16px, 칩은 알약형.
- 카드: panel 바탕 + 1px line 테두리. 오른쪽 위 화살표 원 아이콘(카드가 링크일 때).
- 버튼: 주 버튼 = violet 채움 + 흰 글자 + hover 시 shadow-glow. 보조 버튼 = 투명 + 1px line-strong 테두리 + 흰 글자. 위험 = danger 외곽선. 높이 40px(폰 44px).
- 이모지 금지(v2와 같음). 선 아이콘 1.75px.

## 3. 앱 셸 (v2 구조 유지, 처리만 변경)

- 레일·헤더 바탕 rail, 오른쪽/아래 경계 1px line. 활성 메뉴: violet-soft 배경 + 왼쪽 2px violet 막대 + 아이콘 violet-ink.
- 로고: 부엉이 아이콘 + "OWL COMPILE"에서 "OWL"만 violet-ink (레퍼런스의 "Fin"처럼).
- 헤더 오른쪽 주 동작이 있으면 violet 채움 버튼 하나, 보조는 외곽선 버튼.

## 4. 빛·그라데이션을 쓰는 곳 (여기만)

| 화면 | 처리 |
|---|---|
| 로그인·가입·첫 설정 | 화면 위쪽에 glow-arc, 그 아래 가운데 카드(panel, 1px line-strong, 12px). 카드 위에 제목 "OWL COMPILE"과 한 줄 소개(강조 구 violet-ink) |
| 홈 | 위쪽 옅은 glow-arc + 헤드라인 + 버튼 두 개(참가 = violet 채움, 진행자 화면 = 외곽선). 아래 동작 카드들 중 **"게임 참가" 카드 하나만 bg-highlight**. 그 아래 bg-band 띠에 라운드 5장 카드(투명 + line-on-violet, 큰 Manrope 숫자 01~05, 라운드 이름, 새 요소) |
| 팀 편집기 /play | 평평한 검정 패널(v2 콘솔 레이아웃). 프로그램 패널이 편집 가능할 때만 테두리를 violet 40%로. 제출 버튼 = violet 채움 + shadow-glow. 봉인됨 오버레이 = 패널 위 반투명 검정 + 가운데 violet-ink 자물쇠·문구 |
| 진행자 콘솔 /host | 평평한 패널. "다음 단계" 큰 버튼만 violet 채움 + shadow-glow. 실행 중인 팀 행 = violet-soft + 왼쪽 violet 막대 |
| 프로젝터 /board | 대기 화면: 거대한 glow-arc 아래 흰 헤드라인 "참가 코드" + Manrope/Mono 큰 코드 + 참가 주소 박스(로고 띠처럼 얇은 테두리 둥근 박스, 팀별 접속 수를 세로 구분선으로 나눔). 실행 화면: 뷰포트 테두리 1px line-strong + 바깥 glow-soft 한쪽, 결말 띠 = goal이면 bg-highlight 대신 cyan 테두리 띠, dead/error면 danger 띠. 점수·최종 순위: bg-band 전체 화면 위에 투명 카드들, 1위 카드만 bg-highlight |
| 관리 /admin | 평평한 패널·표. 초대 만들기 버튼만 violet 채움 |

그 밖의 모든 면은 평평한 panel + line. 한 화면에 bg-highlight는 최대 1곳.

## 5. 맵 (검정 바탕)

- 바닥 inset + 격자선 rgba(255,255,255,.04). 벽 #605A7D + 윗변 rgba(255,255,255,.22) 1px (처음 값 #1D1A2B는 바닥 대비 1.17:1이라 벽이 안 보여서 3:1 이상으로 조정). 구덩이: 순검정 원 + 바깥 테두리 rgba(255,255,255,.45) 2px (검은 바닥에서 보이도록). 둥지: cyan 링 + cyan 글로우. 순찰로: danger 점선. 글리프 색은 v2 그대로(쥐 violet-ink, 열쇠 cyan, 문 blue, 고양이 danger). 부엉이 몸통 violet #6E45FF.

## 6. 하지 않는 것

기능·규칙 변경, 새 페이지, 라이트 테마, 이모지, 화면마다 글로우 남발, 모든 카드를 보라로 채우기, 흐린 보라 글자(검정 위 #5B2BFF 글자는 대비가 낮으니 글자는 violet-ink).
