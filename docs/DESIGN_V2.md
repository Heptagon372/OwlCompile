# OWL COMPILE UI 리디자인 v2 — 디자인 브리프 (UI만)

사용자 요청: "너무 아기자기하다. 첨부한 코딩게임 화면처럼 깔끔하게, UI 부분만, 파란색과 보라색으로."
게임 규칙·서버·API·엔진·편집기 규칙은 **바꾸지 않는다**. 바꾸는 것은 화면의 모양(레이아웃, 색, 글꼴, 컴포넌트 스타일, 아이콘)뿐이다.
이 문서가 `plan/cards.html`과 `docs/WEBSITE_SPEC.md` §9의 시각 규칙(색·모양·이모지)을 대체한다. 기능 규칙은 WEBSITE_SPEC 그대로.

## 1. 레퍼런스 (사용자가 보낸 CodinGame "Onboarding" 퍼즐 화면을 글로 옮김)

- **전체**: 어두운 회색 계열 IDE 화면. 화면 전체를 꽉 채우는 앱 레이아웃이고, 페이지가 문서처럼 스크롤되는 느낌이 아니다.
- **왼쪽 아이콘 레일** (폭 약 120px): 맨 위 사용자 아바타 칸(밝은 회색), 아래로 아이콘+작은 대문자 라벨 세로 메뉴(BACK, FORUM, RESULTS, SETTINGS), 맨 아래 강조색으로 채운 FRIENDS 칸.
- **상단 헤더** (높이 약 56px): 왼쪽에 굵은 흰색 페이지 제목("Onboarding"), 오른쪽에 상태 아이콘과 "Best score N/A".
- **본문은 좌우 2열 패널**, 패널 사이 간격 약 12px, 패널은 거의 각진 모서리(2~4px)와 한 톤 밝은 배경으로 구분한다.
  - 왼쪽 위: **게임 뷰어**. 16:9 화면 안에 게임이 재생되고 오른쪽 위에 HUD(점수 숫자 크게, "Enemies in zone" 같은 작은 라벨+값), 가운데 큰 결과 배너("YOU LOSE!"). 뷰어 바로 아래 **재생 컨트롤 바**: 처음으로·한 칸 뒤·재생(크게)·한 칸 앞·끝으로 아이콘, 프레임 카운터 "9/9", 오른쪽에 설정·공유·전체화면 아이콘. 컨트롤 바 위쪽 경계선에 진행 막대(강조색).
  - 왼쪽 아래: **문제 설명 패널**. 섹션 제목 "The Goal", "Rules"가 아이콘과 함께 회색 굵은 글씨. 본문은 밝은 회색. 본문 속 변수 이름(`enemy1`, `dist1`)은 **강조색 배경의 작은 인라인 칩**.
  - 오른쪽 위: **코드 에디터**. 위에 언어 드롭다운("Python 3", 강조색 글씨의 어두운 셀렉트), 오른쪽 끝에 초기화·최대화 아이콘. 줄 번호 거터, 모노스페이스 코드, 문법 색(키워드·주석·문자열).
  - 오른쪽 아래 왼쪽: **Test cases 패널**. 행마다 번호 칩("01"), 이름("Imminent danger"), 오른쪽에 "▶ PLAY TESTCASE" 버튼(어두운 채움, 강조색 글씨).
  - 오른쪽 아래 오른쪽: **Actions 패널**. 큰 버튼 두 개가 세로로: "▶ PLAY ALL TESTCASES", "✓ SUBMIT". 버튼은 패널보다 한 톤 밝은 사각 블록, 아이콘+대문자 굵은 라벨, 강조색.
- **톤**: 배경 #1E2025 전후의 무채색 다크, 패널 #2B2E33 전후, 경계선은 거의 안 보이는 한 톤 차이. 강조색은 딱 하나(원본은 노랑 #F2BB13). 라벨은 작고 굵으며 자간이 약간 넓다. 둥근 알약 버튼, 이모지, 파스텔, 두꺼운 그림자 없음.

## 2. 우리 버전의 방향

"야간 관제 콘솔". 레퍼런스의 구조와 밀도를 따르되, 무채색 대신 **남색 기반 다크**에 **파랑(주 동작)·보라(선택·강조)** 두 가지 강조색을 쓴다. 귀여운 요소(이모지, 둥근 알약, 굵은 900 글씨, 밝은 파스텔 카드)는 전부 걷어낸다.

### 색 토큰 (app/globals.css `@theme`와 CSS 변수로 정의, 컴포넌트는 토큰만 쓴다)

| 토큰 | 값 | 용도 |
|---|---|---|
| bg | #0B0F1A | 앱 바탕 |
| rail | #0E1322 | 왼쪽 레일, 헤더 |
| panel | #131A2B | 패널 |
| panel-2 | #192139 | 패널 머리, 올라온 면, 버튼 면 |
| inset | #0D1220 | 에디터·맵 뷰포트처럼 파인 면 |
| line | #222B45 | 경계선 |
| line-strong | #2F3A5C | 입력칸·표 경계 |
| text | #E6E9F5 | 본문 |
| text-dim | #A2AAC6 | 보조 |
| text-faint | #6C7596 | 캡션·줄 번호 |
| blue | #3D7BFF (hover #5B90FF) | 주 동작 버튼, 링크, 포커스, 진행 막대 |
| violet | #8B5CF6 (soft rgba(139,92,246,.16), ink #C7B5FF) | 선택 상태, 활성 메뉴, 인라인 토큰 칩, 현재 줄 |
| cyan | #22C3E6 | 둥지(목표)·성공 강조 (드물게) |
| danger | #FF5C7A | 에러·사망·상한 초과 |
| warn | #F2B84B | 경고(시간 임박 등, 드물게) |
| ok | #36D3A6 | 연결됨·제출 완료 (드물게) |

- 강조색은 파랑과 보라만 쓴다. cyan·danger·warn·ok는 상태 표시에만.
- 파랑→보라 그라데이션을 큰 면에 깔지 않는다(흔한 AI 디자인). 필요하면 1~2px 선이나 진행 막대에만.

### 블록 카드 색 (역할 = 카드 색, 파랑~보라 계열 안에서 구분)

카드는 5종류가 한눈에 갈려야 한다. 색상(색조) + 밝기 + 채움 방식 + 아이콘으로 구분한다.

| 분류 | 역할 | 기본안 | 글자 |
|---|---|---|---|
| 이동 | Runner | 채움 #3D7BFF (파랑) | #FFFFFF |
| 회전 | Turner | 채움 #22C3E6 (시안) | #04161D |
| 제어 | Controller | 채움 #8B5CF6 (보라) | #FFFFFF |
| 함수 | Architect | **외곽선형**: 바탕 #1B1F46, 테두리·글자 #8C93FF (남보라) | #C9CCFF |
| 특수(잠자기) | Architect | 채움 #D25CF0 (자주) | #FFFFFF |

- 대비는 글자 4.5:1 이상. 값은 대비 계산 후 조정해도 된다(이 표의 구분 원칙은 유지).
- 카드 모양은 연결 게임의 핵심이라 **위 홈 + 아래 돌기, C-블록 머리/입/꼬리 구조는 유지**하되 세련되게: 모서리 4px, 홈·돌기는 낮고 넓게(높이 5~6px), 카드 윗면 1px 밝은 하이라이트, 아래 1px 어두운 선. 글자 600, 14~15px(폰 15px), 아이콘 16px 선 아이콘. 두꺼운 800·900 글씨와 큰 둥근 모서리 금지.
- C-블록 입(mouth)은 inset 색으로 파인 홈처럼 보이고, 왼쪽 세로 막대는 카드 색.

### 글꼴

- UI: Pretendard Variable (400/500/600/700). 900 사용 금지(보드의 큰 숫자만 700).
- 코드·숫자·게임 코드·타이머·줄 번호: JetBrains Mono (Google Fonts) → D2Coding → Consolas. 숫자는 `tabular-nums`.
- 크기(데스크톱 IDE 밀도): 본문 14px, 패널 제목 13px 600 자간 .02em text-dim, 페이지 제목 18px 700, 버튼 13~14px 600. 폰은 본문 15px.
- 영어 라벨을 억지로 넣지 않는다. 한국어 라벨. (레퍼런스의 대문자 라벨 느낌은 굵기·크기·자간으로 낸다.)

### 모양·간격

- 모서리: 버튼·입력·칩 4px, 패널 6px, 시트·모달 8px. 알약형은 상태 칩(작은 점+글자)에만.
- 패널: panel 배경 + 1px line 테두리, 머리 줄 높이 40px(panel-2 또는 아래 1px 선), 안쪽 여백 14~16px. 패널 간격 12px.
- 그림자는 떠 있는 것(시트, 토스트, 드래그 중 카드)에만.
- 아이콘: 1.75px 선 아이콘(인라인 SVG). **UI 전체에서 이모지 금지**(맵의 🐭🔑🚪🐱 포함 → SVG 글리프로).
- 모션: hover·press 120~160ms. 보드 재생 규칙은 그대로.

## 3. 앱 셸

- **데스크톱(≥1024px)**: 왼쪽 아이콘 레일 64px(아이콘 20px + 11px 라벨 세로 배치): 홈, 참가, 진행(host·admin만), 관리(admin만), 계정. 맨 아래 로그아웃. 활성 항목은 왼쪽 2px 보라 막대 + violet soft 배경.
- **상단 헤더** 48px: 부엉이 로고(작게) + 페이지 제목 + 맥락(예: "R3 · 나선 · 게임 2176"), 오른쪽에 상태(연결 점, 타이머, 표시 이름).
- **폰(<768px)**: 레일 대신 상단 헤더 왼쪽 메뉴 버튼(시트로 메뉴). /play는 폰에서 헤더를 최소화.
- 보드(/board)는 셸 없이 전체 화면.

## 4. 화면별 레이아웃

- **/play 팀 편집기** — 레퍼런스와 가장 닮게.
  - 데스크톱: 왼쪽 열(약 42%) = 위 "맵" 뷰어 패널(맵 + 머리 줄에 라운드명·난이도·상한·코딩 시간), 아래 "목표·규칙" 패널(이번 라운드 새 요소 설명, 블록 이름은 보라 인라인 칩 `앞으로`). 오른쪽 열 = 위 "프로그램" 에디터 패널(머리 줄: 블록 수 n/상한 카운터, 저장 상태, 되돌리기; 본문 inset 바탕 + 왼쪽 줄 번호 거터가 카드 줄마다 1, 2, 3…), 아래 두 칸: 왼쪽 "내 카드" 팔레트 패널, 오른쪽 "팀" 액션 패널(팀원 4명 역할·접속 점, 큰 "제출" 버튼 = 파랑 사각 블록 버튼, 아키텍트만).
  - 폰(390px): 헤더(라운드·타이머·n/상한) → 접이식 맵 → 프로그램 → 하단 고정 팔레트 → 제출 바. 가로 스크롤 없음.
- **/board 프로젝터** — 레퍼런스의 게임 뷰어처럼: 테두리 있는 큰 뷰포트에 맵, 오른쪽 위 HUD(팀 이름·점수·틱), 뷰포트 아래 컨트롤 바 모양의 진행 표시(틱 "12 / 37", 진행 막대, 이벤트 로그), 오른쪽 열에 에디터 모양 코드 패널(줄 번호, 현재 줄 보라 하이라이트). 결말 배너는 넓은 띠에 굵은 글자("둥지 도착" cyan, "고양이를 밟았다" danger). lobby·coding·scored·finished도 같은 패널 언어.
- **/host 진행자 콘솔** — IDE 3열 패널: 왼쪽 "진행"(페이즈·큰 다음 단계 버튼·타이머·참가 안내), 가운데 "팀" 표(밀도 높은 표), 오른쪽 "선택한 팀"(코드 패널 + 결과 + 패치·재실행·보너스). 버튼은 레퍼런스 Actions처럼 사각 블록 버튼.
- **홈·로그인·가입·계정·참가·관리**: 셸 안의 패널. 로그인/가입은 가운데 400px 패널(셸 없이), 바탕에 아주 옅은 격자선. 관리 페이지는 밑줄형 탭 + 촘촘한 표(행 40px, hover 행 강조).

## 5. 맵 렌더 (UI 스타일만, 규칙은 그대로)

- 바닥: inset 위에 옅은 격자선. 벽: #28304D 면 + 윗변 1px 하이라이트(블록 느낌, 파스텔 금지). 구덩이: 검은 원 + 안쪽 테두리. 둥지: cyan 링 + 은은한 글로우. 고양이 순찰로: danger 색 점선 테두리.
- 글리프(SVG, 선 1.75px): 쥐(+20) 보라 계열, 열쇠 시안, 문 파랑(열리면 점선·반투명), 고양이 danger. 부엉이는 기하학적 실루엣(보라 몸통, 흰 눈, 시안 부리)으로 다듬고 방향 표시는 작은 화살표.

## 6. 하지 않는 것

기능·규칙·API·DB·엔진 변경, 새 페이지 추가, 라이트 테마, 파랑·보라 외의 새 강조색, 큰 그라데이션 배경, 이모지.
