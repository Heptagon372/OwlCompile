# OWL COMPILE 디자인 v4 — 프리미엄 글래스 (UI만)

사용자 요청: "블럭이 너무 딱딱함, 둥글고 매끈하게", "고급 디자인 느낌으로" + 레퍼런스 이미지(보라 글래스 대시보드).
v3(`docs/DESIGN_V3.md`)의 검정·전기 보라 방향과 v2의 화면 구조를 이어받고, 표면 처리를 **유리(글래스모피즘) + 부드러운 보라 조명 + 둥근 모서리**로 올린다. v3·v2와 충돌하면 이 문서가 이긴다. (v3의 "알약 버튼 금지", "모서리 8/12" 규칙은 폐기)

## 1. 레퍼런스 (사용자가 보낸 "Living Dashboard"를 글로 옮김)

- 아주 어두운 보라검정 바탕 위에 **떠 있는 반투명 유리 패널**들. 패널은 모서리가 크게 둥글고(약 20px), 가장자리에 아주 옅은 흰 테두리, 윗변에 미세한 빛 반사, 뒤로 보라 조명이 번진다. 바탕에는 어두운 입체 블록들이 원근감 있게 깔려 있다.
- 왼쪽 사이드바: 제목 "Living Dashboard", 아이콘+라벨 메뉴. **활성 메뉴는 보라 그라데이션으로 채운 둥근 알약**(빛 번짐 포함). 아래에 "Need Help?" 버튼.
- 상단: 둥근 검색창(유리), 오른쪽에 달력·알림 아이콘 원형 버튼, 둥근 아바타. 오른쪽 위 **보라 그라데이션 알약 버튼** "+ New Request".
- 인사말 "Good Morning, Jordan" + 작은 부제.
- **지표 카드 4장**: 유리 카드, 왼쪽 위에 보라로 빛나는 원형 아이콘 배지, 작은 라벨, 큰 숫자(1,284 / 642 / 532 / 98.6%), 증감 문구, 아래에 네온 보라 스파크라인.
- **영역 차트**: "Service Requests Overview", 네온 보라 선 + 아래로 옅어지는 보라 영역, 최고점에 말풍선 태그 "246 Today"와 빛나는 점, 기간 선택 드롭다운 알약.
- **최근 요청 목록**: 행마다 원형 아이콘, 제목+번호, 오른쪽 상태 알약(In Progress 보라, Pending 호박색, Resolved 초록).
- **지도 카드**: 어두운 지도 위에 빛나는 보라 핀과 네온 경로, 유리 말풍선.
- **원형 진행 링**: 85% 평균 점수, 보라 네온 링 + 순위 목록.
- **빠른 실행 타일**: 아이콘+라벨의 작은 유리 타일들.
- 구석에 **빛나는 반투명 3D 큐브**(안에서 보라빛이 나오는 유리 큐브, 주변에 작은 큐브들).
- 전체 인상: 어둡고 고급스럽고 부드럽다. 딱딱한 선보다 둥근 면, 강한 색보다 은은한 보라 조명.

## 3. 형태·컴포넌트

- 모서리: 입력·작은 버튼 12px, 버튼 알약(9999px), 카드·패널 20px, 시트·모달 24px, 칩 알약.
- 패널(GlassPanel): glass + 1px stroke + sheen + 그림자 0 20px 60px rgba(0,0,0,.45). 머리 줄은 구분선 없이 여백으로(제목 15px 600 + 오른쪽 작은 동작).
- 주 버튼: violet-grad 알약 + 흰 글자 + violet-glow, 호버 시 밝기 +6%·빛 강화, 누르면 살짝 눌림(scale .98). 보조 버튼: glass 알약 + stroke-strong. 위험: danger 외곽선 알약.
- 아이콘 배지: 36~40px 원, violet-grad + 안쪽 흰 선 아이콘 + 은은한 빛.
- 상태 알약: 진행 중 보라, 대기 호박색, 완료 초록, 오류 장밋빛 — 모두 반투명 배경 + 같은 색 글자.
- 지표 카드(StatCard): 배지 + 라벨 + 큰 Manrope 숫자 + 보조 문구 + (선택) 네온 스파크라인.
- 원형 링(RingProgress): 네온 보라 링, 가운데 큰 숫자. 코딩 타이머에 사용(프로젝터·편집기 머리).
- 사이드바(AppShell): 유리 사이드바 폭 232px(데스크톱), 활성 메뉴 = violet-grad 알약 + 빛. 폰은 상단 바 + 메뉴 시트.
- 3D 글로우 큐브(GlowCube): CSS 3D 변환의 반투명 유리 큐브, 안에서 보라빛, 천천히 회전. **대기실에만** 사용. reduced-motion이면 정지.
- 금지: 이모지, 각진 박스 느낌, 채도 높은 원색 면, 글로우 남발(한 화면에 강한 빛 요소 2개까지: 주 버튼 + 한 가지).

## 4. 둥근 블록 (가장 중요)

- 모든 블록: 모서리 14px, 높이 48px(폰 48px, 보드 64px), 글자 15px 600.
- 면: 위에서 아래로 은은한 그라데이션(위 +8% 밝기 → 아래 −8%) + 윗변 1px 흰 반사(18%) + 아래쪽 같은 색 부드러운 그림자(0 6px 18px 색 35%). 유리 광택 느낌.
- 연결 모양: 위쪽 **부드러운 홈**(반원에 가까운 곡선, 폭 32px, 깊이 7px), 아래쪽 같은 모양의 **둥근 돌기**. 각진 사다리꼴 금지. (SVG path 또는 radial mask로 곡선을 만든다)
- C-블록: 머리·입·꼬리의 안쪽 모서리도 둥글게(입 안쪽 12px), 입 바탕은 glass-inset, 왼쪽 팔은 블록 색 그라데이션. 반복 횟수 칩은 흰 반투명 원.
- 색(글자 대비 4.5:1 이상, 서로 구분):
  - 이동(러너): 파랑 그라데이션 #5A86FF → #3A5FE0, 흰 글자
  - 회전(터너): 시안 그라데이션 #3FD6F2 → #1799BD, 글자 #04161D
  - 제어(컨트롤러): 보라 그라데이션 #9670FF → #6B3FEA, 흰 글자
  - 함수(아키텍트): 유리형(반투명 라벤더 rgba(180,155,255,.16) + 1.5px #B49BFF 테두리), 글자 #E6DDFF
  - 특수(잠자기): 자주 그라데이션 #C065E8 → #8E3BB8, 흰 글자
  (값은 대비 계산 후 조정 가능. 원칙: 둥근·광택·부드러운 그림자)
- 드래그 중: 카드가 살짝 커지고(1.03) 빛이 강해진다. 연결 지점: 네온 보라 선(끝에 빛나는 점). 고스트: 점선 둥근 외곽선.
- 놓는 순간: 카드 테두리에 네온 링이 0.6초 번쩍(FEATURE_V4 §4와 동기).

## 5. 네온 코드 뷰

- 코드 패널: glass-inset 위 JetBrains Mono 14px, 줄 번호 text-faint, 문법 색: keyword #C4A8FF, builtin #7FF0FF, call #F4F1FF, number #F5B94A, punct #8C86A8, comment #6F6A8C.
- 새 줄: 타이핑 + neon-violet 글로우가 1.2초에 걸쳐 잦아듦 + 줄 배경에 왼→오 빛줄기(보라→투명) 1회. 바뀐 줄: 0.6초 글로우. 현재 실행 줄(보드): 줄 전체에 violet 16% 배경 + 왼쪽 3px 네온 막대 + neon-cyan 글자 빛, 부드럽게 이동.
- 패널 가장자리에 아주 옅은 스캔라인(투명도 3%)로 모니터 느낌. reduced-motion이면 끔.

## 6. 화면별

- **대기실 /lobby**: 가운데 큰 GlowCube, 인사말 "안녕하세요, 김하늘님", 상태 문구("진행자가 게임을 만들면 자동으로 입장합니다"), 대기 인원 StatCard(숫자 크게) + 대기 명단(둥근 이니셜 아바타 줄), 열린 게임 카드 목록, 보조로 "게임 코드로 참가" 입력. 배정 알림이 오면 큐브가 한 번 밝게 빛나고 "수리부엉이 팀 · 러너로 배정됐어요" 토스트 후 이동.
- **홈**: 인사말 + 지표 카드 4장(관리자: 대기 인원·진행 중 게임·가입 회원·열린 초대 / 참가자: 대기실 바로가기 중심) + 빠른 실행 타일(게임 만들기·초대 만들기·프로젝터 열기·대기실). 초대는 관리자만 만들 수 있으므로 진행자 홈에서는 "초대 만들기" 자리에 "내 계정" 타일을 둔다.
- **진행자 /host**: 왼쪽 "대기실" 유리 패널(실시간 인원 링 + 명단), 가운데 "새 게임" 패널(팀 수 2~10 세그먼트 또는 슬라이더 + 추천값 표시, 라운드 칩 1~7 + 프리셋 알약, 배정 방식 토글, 미리보기: 팀별 예상 인원), 오른쪽 내 게임 목록. 콘솔은 v2 3열 구조를 유리 패널로. 팀 표는 10팀까지 스크롤 없이(행 44px).
- **팀 편집기 /play**: v2 구조를 유리 패널로. 오른쪽 영역 = 블록 편집기 | 네온 코드 뷰 나란히(데스크톱). 머리에 RingProgress 타이머. 팀 패널은 최대 6명(역할 알약 여러 개).
- **프로젝터 /board**: 대기 화면 = GlowCube 대신 거대한 보라 조명 + 참가 안내, 코딩 = 거대한 RingProgress 타이머 + 맵, 실행 = 맵 + 네온 코드 뷰(path 강조), 점수 = 유리 순위 카드(10팀까지 2열).
- **로그인·가입·설정·관리**: 유리 카드, 둥근 입력, 알약 버튼. 관리 표는 유리 패널 안.
